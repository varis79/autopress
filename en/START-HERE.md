# Start here — Autopress

Build your own **news-curation media outlet that publishes itself**, with the help of an AI.
Español: [EMPIEZA-AQUI.md](../EMPIEZA-AQUI.md).

## What you need
- An **AI with terminal and file access** (a code agent): **Claude Code** or **Cursor**
  (recommended), or ChatGPT in agent/Codex mode.
  > A plain chat (ChatGPT/Claude web) is fine for the **questionnaire and generating the
  > config**, but it **can't run** the commands for you. To actually build and deploy, use a
  > code agent.
- A few minutes. **Nothing else is required upfront**: without a domain, feeds, or an AI key
  you can still move forward (see the levels in [00-QUICKSTART.md](00-QUICKSTART.md)).

## How to start (2 steps)
1. **Download the kit** (ZIP from `/releases/latest`) and open it with your code agent.
2. **Paste this starting prompt:**

```
Here's the Autopress kit (these files). Help me set up my own AI-powered news outlet. I'm
NON-technical. Read AGENTS.md and follow it: walk me through it step by step, running the
commands yourself and waiting for my answers. Don't publish anything without my go-ahead.
```

*(Everything else — the flow, the questionnaire, picking feeds, deploy — is already in
`AGENTS.md`; the agent reads it and guides you, starting with a welcome.)*

3. From there, the agent guides you. Not sure what's configurable? Say *"show me the settings"*.
